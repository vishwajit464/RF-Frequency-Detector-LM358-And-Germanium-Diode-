# 📡 RF Frequency Detector Using LM358 & Germanium Diodes

**A simple DIY RF Signal Detector using LM358 Operational Amplifier and two 1N34 Germanium Diodes.**


##  Project Overview

The RF Frequency Detector is a simple and low-cost electronic project designed to detect the presence of Radio Frequency (RF) signals.

This circuit uses two Germanium diodes (1N34) to detect and rectify RF signals. The LM358 operational amplifier processes the detected voltage, and an LED provides a visual indication when the circuit responds to an RF signal.

The project is built on a general-purpose PCB and powered by a single 3.7V Lithium-Ion battery.

## ⚙️ Working Principle

The circuit works based on the detection of RF signals using Germanium diodes and an operational amplifier.

1. **RF Signal Reception:** The antenna receives nearby RF energy.
2. **Signal Detection:** Two 1N34 Germanium diodes are used in the input detection stage.
3. **Signal Processing:** The LM358 operational amplifier processes the detected voltage.
4. **Output Indication:** When the detected signal causes the amplifier output to change, the LED provides a visual indication.

**Note:** This is an RF signal presence detector, not a calibrated frequency meter. Its detection sensitivity depends on the circuit construction, antenna, and signal strength.

The project uses one amplifier section of the LM358 IC.
